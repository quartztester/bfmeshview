# ARCHIVE NOTES

This is a **community preservation archive** of **BfMeshView**, a free / open-source
Battlefield mesh viewer and modding tool written in Visual Basic 6 by
**Martijn** of **bytehazard.com**.

* Original project page: <http://www.bytehazard.com/bfstuff/bfmeshview/>
* Original author contact: martijn@bytehazard.com
* Original release downloads live under the page above (`bfmeshviewXYZ.zip`).

## What this repository is (and is not)

This history was **reconstructed in 2026** directly from the original per-release
download archives. Each release zip (binary `BfMeshView.exe`, the bundled VB6
source where the author shipped it, and the DLL/OCX runtimes) was downloaded,
extracted, and committed as a single **release-per-commit** tree, oldest to
newest, with an **annotated tag** (`vX.Y.Z`) on each commit.

Therefore:

* **Tags match the original release zips** — checking out a tag reproduces that
  release's shipped files.
* **Commit history is a release timeline, not a line-by-line development
  history.** There are no intermediate development commits; the diff between two
  adjacent tags is simply the set of files that changed between those two
  shipped releases.
* Commit **authorship is attributed to the original author** (Martijn /
  martijn@bytehazard.com) and author/committer **dates are the original release
  dates**, so `git log` reads as a faithful release timeline. The committer
  identity (`quartztester`) is the archivist who performed the reconstruction.

The top-level `README.md` documents the final (v2.5.3) state and is a
reconstruction-era addition committed after the last version tag; it is not part
of any original release.
